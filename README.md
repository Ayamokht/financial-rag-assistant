# 🤖 Financial RAG Assistant

> 🚧 Project under development

A Retrieval-Augmented Generation (RAG) project for querying and analyzing public financial documents using Large Language Models.

## 🎯 Objective

The objective of this project is to build a RAG pipeline capable of:

- ingesting financial documents,
- extracting and chunking their content,
- generating embeddings,
- retrieving relevant information,
- generating answers grounded in the retrieved documents,
- providing sources for generated answers.

## 🧠 Topics explored

- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Embeddings
- Semantic Search
- Vector Databases
- RAG Evaluation

## 🏗️ Current status

Setting up the project architecture and preparing the document ingestion pipeline.
